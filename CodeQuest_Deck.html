The Problem

A developer's progress is scattered everywhere

WHY THIS PROJECT
EXISTS

01Fragmented identity

Five platforms, five logins, five different stat pages. No single place that says “this is my actual coding profile.”

02No unified truth

Solved counts, streaks and contest ratings live in separate dashboards. Students track the rest in spreadsheets and memory.

03Weak motivation loop

No shared goals, no accountability, no visible milestones. Consistency is hard to maintain without feedback.

04No shareable proof

Recruiters and peers cannot see a consolidated, credible snapshot of real practice outside a resume line.

!Result

Effort becomes invisible, and consistency becomes hard to prove — even when the work is real.

CodeQuest · Database06 / 19
End-to-End

How the core journey works

REGISTER → SYNC → INSIGHT

1Authenticate

Register/login → password hashed with bcrypt (12 rounds) → signed JWT stored in localStorage and sent as Bearer token.

2Connect

User enters a platform handle → backend fetches public data → upserts a PlatformAccount with stats + daily history.

3Aggregate

/api/dashboard merges all accounts and verified activity into one timeline and totals.

4Derive

Streak, longest streak, score, XP, level, badges and Developer DNA are computed on read.

5Showcase

Public page /u/:username, printable dossier, and /api/cards/:username.svg for GitHub READMEs.

Design note: every derived metric is computed on request from stored raw data — no denormalised counters to keep in sync.

Feature Deep-Dive

Dashboard metrics & formulas

COMPUTED ON READ

ΣTotals & streak

// solved from accounts + verified activity
solved = Σ account.stats.solved
total = solved + Σ verifiedActivity.solved

// consecutive-day run over merged dates
longest = max consecutive days
streak = current run if last day ∈ {today, yesterday}

◔Progress score (0–100)

score = min(100, round(
  min(solved,500)/500 * 35
+ min(longest,30)/30 * 25
+ min(accounts,4)/4 * 15
+ min(verifiedActs,100)/100 * 25 ))

⚡XP & level

xp = totalSolved*10
      + longestStreak*25
      + platforms*50

level = max(1, floor(xp / 500) + 1)
next = 500 - (xp % 500) XP

▦365-day heatmap

// merge platform history + verified logs
byDay[date] += history[date]
byDay[date] += verifiedActivity[date]

// intensity levels
≥8 → 4 · ≥5 → 3 · ≥3 → 2 · ≥1 → 1
CodeQuest · Analytics09 / 19
Feature Deep-Dive

Developer DNA radar

6-AXIS SKILL MODEL

◔Six computed axes (0–100)

Data Structures = easy*.15 + medium*.4 + hard*.9 + solved*.1
Algorithms = cfRating/18 + cfSolved*.2 + bonus(>1400)
Real-world Dev = ghRepos*4.5 + ghFollowers*5 + 20
Speed & Grit = streak*3.5 + verifiedDays*.3 + 25
Problem Solving = totalSolved/7 + 25
Math & Logic = cfRating/22 + medium*.25 + 30

Each axis is clamped to 100 with a small floor so the radar always renders meaningfully.

★Archetype ladder

  • rating ≥ 1600 → Grandmaster Algorithmist
  • LeetCode solved ≥ 350 → DSA Specialist
  • repos ≥ 6 & solved ≥ 150 → Full-Stack Craftsman
  • streak ≥ 14 or days ≥ 50 → Tenacious Grinder
  • platforms ≥ 3 → Polyglot Problem Solver
  • default → Rising Challenger

Rendered with a Recharts RadarChart plus per-axis progress bars.

CodeQuest · Readiness13 / 19
Engineering

Security & reliability

DEFENCE IN DEPTH

🔒Passwords

bcrypt, 12 rounds; hash never returned (select:false).

🔑Sessions

Signed JWT, 7-day expiry, verified on every protected route.

✓Validation

express-validator on inputs + Mongoose schema constraints.

⏱Rate limits

Auth 40/15min; sync 15–30/min to protect upstream APIs.

🛡Hardening

helmet headers, 32 KB JSON cap, CORS, central error handler.

⛁Integrity

Unique indexes prevent duplicate accounts, portfolios, quests.

🌐DNS fix

Custom resolver for MongoDB SRV when ISP DNS fails.

☁Deploy guard

Production refuses weak JWT secrets; SPA + API on one host.

Engineering

Challenges & solutions

REAL-WORLD FIXES

1MongoDB SRV not resolving

Fix: custom dns.lookup override using public resolvers, then fall back to system lookup.

2Codeforces rate limits

Fix: a promise queue enforcing a 2.2s gap between requests, with graceful partial failure.

3Inconsistent platform APIs

Fix: one normalised stats shape across REST, GraphQL and HTML sources.

4Slow dashboard

Fix: parallel queries with Promise.all and bounded result limits.

5SPA routing on one host

Fix: Express static serving with an index.html fallback for non-API routes.

6Dev proxy mismatch

Fix: Vite proxies /api to the backend port so cookies/headers stay same-origin.

CodeQuest · Challenges16 / 19
Honest Scope

Known limitations

WHAT IS NOT DONE YET

!Product gaps

  • Manual entries are labelled unverified but still count in some totals.
  • “AI” readiness and daily quest are deterministic heuristics, not an LLM.
  • Quest/duel XP messages are not persisted to the XP ledger.
  • Duels use manual polling, not live WebSocket updates.
  • No email verification, password reset or username change.

⚠Technical risks & fixes

  • Leaked example credentials in a committed file → rotate secrets immediately.
  • HTML scraping for CodeChef/GFG is fragile → move to stable APIs.
  • GitHub sync ignores the token → 60 req/hour per IP limit.
  • Leaderboard runs N+1 queries → aggregate pipeline needed.
  • No automated tests or CI → add coverage before scaling.
